# 决策记录 · {你的名字}

> 每人一份，文件名用你的名字：`docs/decisions/张三.md`
> **每做一个决策就写一条。** 期末这份文件直接就是你的面试稿。

---

## 模板

```markdown
## 2026-11-20 · 标题（一句话说清这个决策是什么）

- **问题**：我在纠结什么？（例：任务状态该存在内存里还是数据库里）
- **选项**：
  - A：xxx —— 优点 / 缺点
  - B：xxx —— 优点 / 缺点
- **我的选择**：B
- **为什么**：选 B 的关键理由是……
- **不这么选会怎样**：如果选 A，会出什么问题
- **验证方式**：我怎么确认这个选择是对的
```

---

## 为什么这个文件重要

**代码可以抄，决策抄不了。**

一个人如果真做了，他能说出「我一开始想 X，结果发现 Y，所以改成 Z」。
只复制了代码的人写不出这一段。

这份文件也是面试时唯一能证明「你是真的想过」的东西。
