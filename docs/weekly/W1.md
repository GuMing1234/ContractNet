## 四、组会议程（90 分钟）

| 分钟 | 环节 | 要点 |
|---|---|---|
| 0–10 | 项目全貌 | 一句话定位 + 三大创新点 + 与现成框架的差异。**不讲架构细节** |
| 10–25 | **现场演示** | 跑骨架 → 展示「任务派给了正确的 Agent」；讲 3 个已知设计陷阱 |
| 25–35 | 本周验收 | 逐个确认自测完成情况与 PR，未完成的当场说明 |
| 35–45 | 设计与分工说明 | 讲 `docs/04-design.md` 的章节目录 + 12 个模块的分工原则 |
| 45–75 | **认领** | 逐个模块认领，当场登记；每人说一句「我这块的输入输出」 |
| 75–85 | 规则与节奏 | 六条铁律 + 周五组会 + 每日三行 |
| 85–90 | 下周目标 | 明确 W2 是接口冻结周，产出物是什么 |

**会前必做**：每人交 3 行（上周完成 / 本周计划 / 阻塞点）。
